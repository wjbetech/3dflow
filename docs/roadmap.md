# Roadmap

## Phase 1: Foundation

- Set up the repository, local tooling, and 3D viewport
- Build preset irregular shapes plus a custom-shape control surface
- Add the first irregularity check and interaction toggles
- Document the product direction and technical assumptions

## Phase 2: Shape authoring

- Add direct-manipulation controls for handles, curves, and local deformation
- Support shape import/export and saved presets
- Improve irregularity detection with symmetry, curvature, and primitive-fit checks
- Add history, reset, and comparison tools

## Phase 3: Simulation fidelity

- Introduce a dedicated fluid state engine
- Track volume conservation and container occupancy more accurately
- Expand gravity, pour, splash, and impact modes into parameterized simulation presets
- Add collision tuning, viscosity options, and surface-tension experiments

## Phase 4: Scientific validation

- Create benchmark scenes with known expected outcomes
- Compare results against analytical or reference-simulation baselines
- Surface confidence indicators and error bounds in the UI
- Document the difference between preview mode and validated mode

## Phase 5: Product polish

- Build scenario saving and reproducible share links
- Add tutorials, presets, and educational overlays
- Improve performance profiling and adaptive quality settings
- Prepare deployment, analytics, and structured feedback loops
