# Vision

## Product goal

3dflow should become a practical sandbox for exploring how water behaves inside non-standard containers and irregular solid forms. The experience needs to feel approachable enough for experimentation while staying anchored in physically defensible simulation choices.

## Core use cases

- Browse a library of irregular 3D shapes and inspect how their geometry affects filling behavior.
- Create a brand-new irregular vessel, tune its shape, and receive feedback if it drifts into a regular form.
- Tilt the object across X and Y axes while adjusting fill volume.
- Switch between simplified interaction presets and more accurate gravity-driven behavior.
- Study pouring, splash, and impact-bounce responses under configurable conditions.

## Product principles

- Accuracy with transparency: if a view is approximate, the interface should say so clearly.
- Customization without chaos: expose useful knobs, but group them into understandable modes.
- Shape-first workflow: the vessel geometry is not an afterthought; it is central to every interaction.
- Scientific credibility: long-term success depends on calibration, reference scenarios, and measurable outputs.

## Intended users

- Designers exploring unusual vessels or installations
- Students learning intuition for fluid and shape mechanics
- Makers and technical artists prototyping interactive simulations
- Educators who need a visually compelling mechanics sandbox

## Definition of success

The mature product should let a user create or load an irregular shape, validate that shape classification, choose a simulation fidelity level, and obtain both a readable visual result and a set of trustworthy physical metrics.
